1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
GearUp is a modern, responsive Next.js 15 (App Router) sports and outdoor equipment 
rental web application. It allows customers to browse rental gear, filter by category 
and price, select dynamic rental dates, calculate costs in real-time, and complete 
secure payments via Stripe. 

Gear Providers can list equipment inventory and fulfill incoming rental orders by 
updating order statuses. Admins oversee the entire platform through user moderation 
tables, global analytics, and category management.


2. TECH STACK & LIBRARIES
--------------------------------------------------------------------------------
- Core Framework: Next.js 15.1.6 (App Router, Server/Client Components, Edge Middleware)
- Language: TypeScript 5.7.3 (Strict Mode)
- Styling: Tailwind CSS v4.0, Custom Glassmorphism CSS, Lucide React Icons
- State Management: Zustand 5.0 (Global Auth State Store with Token Persistence)
- HTTP Client: Axios 1.7 (With Request Bearer Interceptor & Sonner Toast Error Notifications)
- Forms & Validation: React Hook Form 7.54 + Zod 3.24 Schema Resolver
- Payment Gateway: Stripe Checkout & Stripe Elements (@stripe/stripe-js, @stripe/react-stripe-js)
- Toast Notifications: Sonner 1.7


3. ROLES & PERMISSIONS MATRIX
--------------------------------------------------------------------------------
ROLE        DESCRIPTION               FRONTEND UI EXPECTATIONS & CAPABILITIES
--------------------------------------------------------------------------------
Customer    Users who rent gear       Public catalog browsing, search & filters, 
                                      interactive rental date pickers, Stripe 
                                      checkout flow, customer dashboard (rental 
                                      history & payment receipts), star rating 
                                      review submission for returned gear.

Provider    Gear rental vendors       Provider dashboard, equipment inventory 
                                      listing modal (with image URL, stock, daily 
                                      rate), order fulfillment table with status 
                                      transition controls (CONFIRMED, PICKED_UP, 
                                      RETURNED, CANCELLED).

Admin       Platform moderators       Admin dashboard, user moderation table 
                                      (ACTIVE vs SUSPENDED toggle), global platform 
                                      analytics cards, category manager modal.

5. API ENDPOINTS MAPPING MATRIX
--------------------------------------------------------------------------------
MODULE          METHOD   ENDPOINT                          ROLE REQUIRED
--------------------------------------------------------------------------------
Auth            POST     /auth/login                       Public
Auth            POST     /auth/register                    Public
Auth            GET      /auth/me                          Bearer Token

Categories      GET      /categories                       Public
Categories      POST     /categories                       Admin

Gear            GET      /gear                             Public
Gear            GET      /gear/:id                         Public
Gear            POST     /gear                             Provider / Admin

Orders          POST     /orders                           Customer
Orders          GET      /orders/my-orders                 Customer / Provider
Orders          PATCH    /orders/:id/status                Provider / Admin

Payments        POST     /payments/create-checkout-session Customer
